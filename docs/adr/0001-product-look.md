# Typography and composition first

The product uses Swiss-influenced editorial composition with brutalist restraint. Typography establishes hierarchy, and alignment, scale, whitespace, and cropping establish structure; controls stay visually quiet at rest so they do not compete with the page, while semantics, hit areas, focus, and interaction feedback remain clear.

The base is near-monochrome. Accent color is a brief signal for a meaningful change, not ambient decoration. Glitch and color split were dropped: they are not a treatment this product ships. Dashboard chrome, fake telemetry, scanlines, terminal ornament, glow, and generic SaaS control styling are rejected because they make interface decoration compete with content.
